# Dragon-Asteroid-Run

Dragon Asteroid Run adalah game arcade sederhana bertema luar angkasa yang dibangun menggunakan bahasa C++ dan library grafis SIGIL (Simple Graphics Interface Library). Pemain mengontrol seekor naga untuk menghindari asteroid dan bertahan hidup selama mungkin.

🚀 Cara Instalasi (Untuk Pemain)
Jika kamu hanya ingin memainkan gamenya, ikuti langkah ini:
Unduh file DragonAsteroidRun_Installer.zip dari repositori ini.
Ekstrak file ZIP tersebut.
Jalankan Setup.exe.
Jika muncul peringatan "Windows Protected Your PC", klik "More Info" lalu pilih "Run Anyway".
Game siap dimainkan dari Shortcut Desktop!

🛠️ Untuk Pengembang (Source Code)
Repositori ini juga menyertakan source code asli sebelum dipaketkan.
Bahasa: C++
Library: SIGIL (Sudah termasuk dalam folder lib/include)
IDE: Visual Studio 2022 (direkomendasikan)
Cara Build dari Source:
Buka file .sln menggunakan Visual Studio.
Pastikan konfigurasi diatur ke Release dan x64/x86 (sesuai library).
Pastikan folder assets berada di direktori yang sama dengan hasil build .exe.

🎮 Kontrol Game
Panah Atas: Gerak ke Atas
Panah Bawah: Gerak ke Bawah
ESC: Pause Game
Enter: Mulai Game / Pilih Menu
Q: Keluar dari Game
